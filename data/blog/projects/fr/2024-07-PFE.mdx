## Contexte
Projet de fin d'études de 6 mois à onepoint, Paris.
Conception et implémentation d'une solution de cloud messaging pour une application mobile multi-plateforme et multi-marché.

## Equipe projet


## Travaux réalisés
* Conception, développement et déploiement d’une API via des fonctions lambda AWS pour envoyer des notifications push à des appareils mobiles mais aussi créer, modifier et utiliser des templates de notifications.
* Développement de nouvelles routes et fonctionnalités pour le backend d’une application mobile multi-plateforme et multi-marché.
* Développement de scripts d’automatisations (génération de code, tests et Github Actions)
* Optimisations de code et d’infrastructure (Terraform)

## Certifications obtenues
* AWS Certified Developer - Associate
* Terraform Associate

## Technologies utilisées
* AWS (Lambda, S3, API Gateway, DynamoDB, SNS, CloudWatch)
* Node.js, Typescript, Fastify
* Terraform
